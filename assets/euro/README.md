# Recursos oficiales de euros para el arqueo

Estos recursos se utilizan únicamente como apoyo visual para el conteo de efectivo en el preview de QA.

## Billetes

- Fuente: Banco Central Europeo (BCE).
- Paquetes de origen: `Banknotes ES1 Specimen 72dpi.zip` y `Banknotes ES2 Specimen 72dpi.zip`.
- Recursos incluidos: imágenes JPG de baja resolución con la marca `SPECIMEN`.
- Se utilizan los billetes de la serie Europa con firma Lagarde para 5, 10, 20, 50, 100 y 200 euros, y la imagen oficial de la primera serie para 500 euros.
- Condiciones: [imágenes y reglas de reproducción del BCE](https://www.ecb.europa.eu/euro/banknotes/images/html/index.en.html) y [FAQ de reproducción](https://www.ecb.europa.eu/euro/banknotes/images/html/ecb.faq_reproduction_rules_euro_banknotes.en.html).

La marca `SPECIMEN` no se elimina. Las imágenes se sirven a tamaño reducido desde el mismo dominio de la aplicación y no se usan para impresión.

## Monedas

- Fuente: Comisión Europea / Unión Europea.
- Recursos incluidos: caras comunes de las monedas de 1 céntimo a 2 euros.
- Página de origen: [caras comunes de las monedas de euro](https://economy-finance.ec.europa.eu/euro/euro-coins-and-notes/euro-coins/common-sides-euro-coins_en).
- Reglas: [copyright y reproducción de monedas y billetes](https://economy-finance.ec.europa.eu/euro/euro-coins-and-notes/copyright-and-reproduction-rules-euro-coins-and-notes_en).

Solo se muestran como referencia visual dentro de un control de conteo; no se reproducen en objetos físicos ni se presentan como monedas reales.
